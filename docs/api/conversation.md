# Conversation API

## DTO Schema

### `ConversationSummary`
```
{
  "id": UUID string,
  "type": "DIRECT" | "GROUP",
  "membersPreview": UserResponse[],
  "memberCount": number,
  "groupCreatorId": number | null,
  "lastReadSeq": number,
  "createdAt": string,
  "lastMessage": MessageResponse | null
}
```
- `membersPreview` contains the userId and usernames of at most 3 other members, in lexicographical order. It does not include the authenticated user.
- `memberCount` does not include the authenticated user. e.g., A direct conversation has a `memberCount` of 1, not 2.
- `groupCreatorId` is only used for group conversations and is `null` for direct conversations.
- `lastReadSeq` is the highest conversation sequence the authenticated user has read.
  - A value of 0 means no messages have been read.
- `lastMessage` uses the standard `MessageResponse` shape defined in the [Message API documentation](./message.md). It is `null` for an empty conversation (this only applies to `GET /conversations/{conversationId}/summary` — the bootstrap list endpoint never returns empty direct conversations, see below).


### `ConversationDetail`
```
{
  "id": UUID string,
  "type": "DIRECT" | "GROUP",
  "otherMembers": UserResponse[],
  "blockedMe": boolean,
  "groupCreatorId": number | null,
  "isClosed": boolean,
  "lastSeqSnapshot": number,
  "myLastReadSeq": number,
  "createdAt": string
}
```

- `otherMembers` exclude the authenticated user.
- `blockedMe` is only meaningful for DIRECT conversations, and defaults to `false` for GROUP. `true` means the other user has blocked the authenticated user (note: this does not tell you whether the authenticated user has blocked the other way around).
- `isClosed` is only meaningful in GROUP conversations, and defaults to `false` for DIRECT.
- `lastSeqSnapshot` is the conversation's `last_seq` at the moment this detail was fetched. Used by the frontend as a snapshot to decide where to place the "new messages" divider; it intentionally does not update live as new messages arrive in an already-open conversation.
- `myLastReadSeq` is the authenticated user's `last_read_seq` at the moment this detail was fetched (also frozen for the divider logic — see `activeConversationStore`'s distinction between this and the live `ackedSeq`).

## Errors

See [API Errors](./errors.md) for the response shape and the full `ApiErrorCodes` table.

#### `401 Unauthorized` — `UNAUTHORIZED`

The request does not contain a valid authenticated session.


# Conversation Data API 

## Get Conversation Summaries

Fetch lightweight information about conversations that the authenticated user is a member of.

Empty direct conversations are not returned.

### Request
```
GET /conversations
```

### Response
#### `200 OK`
Returns an array of `ConversationSummary`.


## Get Conversation Summary

### Request
```
GET /conversations/{conversationId}/summary
```

### Response
#### `200 OK`
Returns a `ConversationSummary`. Unlike the bootstrap list endpoint, this one does return a summary for an empty conversation (`lastMessage: null`).

#### `404 Not Found` — `CONVERSATION_NOT_FOUND`
Conversation was not found, or user is not a member. The response does not distinguish which.


## Get Conversation Detail

Called when the user opens a conversation.

### Request
```
GET /conversations/{conversationId}
```

### Response

#### `200 OK`

Returns a `ConversationDetail` object.

#### `404 Not Found` — `MEMBERSHIP_NOT_FOUND`

User is not a member of the conversation. (Not `403` — membership lookup is the same code path used elsewhere as a combined existence+membership check, see `markAsRead` below for the same pattern.)

#### `404 Not Found` — `CONVERSATION_NOT_FOUND`

Conversation was not found.


# Conversation Creation API


## Get or Create Direct Conversation

Fetch the ID of the direct conversation between the authenticated user and the target user.

If it didn't exist, one is created and returned, making it idempotent.

### Request
```
POST /conversations/direct/{targetId}
```

### Response

#### `201 Created`

Returns the UUID string of the conversation.

#### `400 Bad Request` — `NO_SELF_DIRECT_CONVERSATION`

Authenticated user attempted to create a direct conversation with themselves.

#### `404 Not Found` — `USER_NOT_FOUND`

Target user was not found.


## Create Group Conversation

Create a group conversation.

### Request
```
POST /conversations/group
```

#### Body
```
{
  "initMemberIds": number[],
  "clientId": UUID string
}
```

- `initMemberIds` should not include the requester.
- `initMemberIds` must contain at least 2 and at most 99 other members (the requester makes up the +1 to the group's 3–100 member bounds).
- `initMemberIds` should be members that are invitable. See ["Get Invitable Users" section in the user-relation docs](./user-relation.md#get-invitable-users)
- `clientId` is an idempotency key generated by the client, and doubles as the resulting conversation's ID.

### Response

#### `201 Created`
Returns the UUID of the created (or already present) group conversation.

If the group conversation was newly created (not already present for this `clientId`), a `GROUP_CREATED` event message is persisted and a corresponding `NEW_MESSAGE` realtime event is broadcast to all initial members. If the group already existed for this `clientId`, nothing further happens — the endpoint silently returns the same ID.

#### `400 Bad Request` — `GROUP_TOO_SMALL`
`initMemberIds` has fewer than 2 entries after removing duplicates.

#### `400 Bad Request` — `GROUP_TOO_BIG`
`initMemberIds` has more than 99 entries after removing duplicates.

#### `409 Conflict` — `MEMBERS_NOT_INVITABLE`
One or more members in the list cannot be added, due to not being "invitable". See below for qualifications of being invitable.


# Group Conversation Membership API


## Get Invitable Users

Gets the list of users that are invitable to the user's group conversation.

Unlike the ["Get Invitable Users" in user-relation](./user-relation.md#get-invitable-users), this API takes a conversation ID as a parameter and filters those who are already in the conversation.

So the result is composed of: Users in the authenticated user's contact list, minus those who blocked the authenticated user, and minus those who are already in the given conversation.

### Request
```
GET /conversations/{conversationId}/invitable
```

### Response

#### `200 OK`
Returns a list of `UserResponse`.


## Invite Members

Invites one or more users to an existing group conversation.

The authenticated user must be the creator of this group.

The users must be currently invitable by the creator, see above for the qualifications for an invitable user.

Adding the users must not push the group over its maximum member count, which is 100 for now. This check is done under an advisory lock (`lockGroupInvite`) to close the TOCTOU window on concurrent invites — see `devlog/010-concurrency_control.md`.

### Request
```
POST /conversations/{conversationId}/members
```
#### Body
```
{
  "memberIds": number[]
}
```

### Response
#### `204 No Content`
Members were successfully added. A `MEMBERS_INVITED` event message is persisted (triggering a `NEW_MESSAGE` realtime event broadcast to all members, including the newly invited ones), and a separate `MEMBERS_ADDED` realtime event is also broadcast to all members (including the newly invited ones) — this is the dedicated structural-sync event the sidebar/active-conversation stores react to; see [realtime docs](./realtime.md#members_added).

#### `400 Bad Request` — `GROUP_TOO_BIG`
The provided list is empty (bean validation, `VALIDATION_ERROR`), or adding the users would exceed the group's maximum member count (`GROUP_TOO_BIG`).

#### `403 Forbidden` — `NOT_GROUP_CREATOR`
The authenticated user is not the creator of this group.

#### `404 Not Found` — `CONVERSATION_NOT_FOUND`
The conversation does not exist, or is not a GROUP conversation.

#### `409 Conflict` — `GROUP_CLOSED`
The group is closed.

#### `409 Conflict` — `MEMBERS_NOT_INVITABLE`
One or more members in the list cannot be added (not a contact of the creator, have blocked the creator, or are already a member of this conversation).


## Leave Group Conversation

Requests to leave a group conversation.

Authenticated user must not be the creator of the group.

### Request
```
DELETE /conversations/{conversationId}/members/me
```

### Response

#### `204 No Content`
Successfully left the group.

A `MEMBER_LEFT` event message is persisted (triggering a `NEW_MESSAGE` realtime event broadcast to the remaining members).

A `MEMBER_REMOVED` realtime event is also broadcast to the remaining members, carrying the updated members-preview patch and member count — see [realtime docs](./realtime.md#member_removed).

A `REMOVED_FROM_GROUP` realtime event is sent to the leaving user's own WebSocket sessions, so their other open tabs/devices drop the conversation too.

#### `400 Bad Request` — `CREATOR_CANNOT_LEAVE`
User is the creator of this group.

#### `404 Not Found` — `MEMBERSHIP_NOT_FOUND`
User was not a member of this group. (Not `403` — see note under Get Conversation Detail.)

#### `404 Not Found` — `CONVERSATION_NOT_FOUND`
The given `conversationId` was not found, or is not a group conversation.

#### `409 Conflict` — `GROUP_CLOSED`
The group is closed.


## Remove Group Member

Removes a member from a group.

The authenticated user must be the creator of this group.

### Request
```
DELETE /conversations/{conversationId}/members/{targetId}
```

### Response
#### `204 No Content`
Member was successfully removed, or wasn't present (removal is idempotent — a no-op target or a target that's already gone both return `204`).

On an actual removal: a `MEMBER_REMOVED` event message is persisted (triggering a `NEW_MESSAGE` realtime event broadcast to the remaining members), a `MEMBER_REMOVED` realtime event is broadcast to the remaining members (preview patch + member count, same as Leave above), and a `REMOVED_FROM_GROUP` realtime event is sent to the removed user's own sessions.

#### `400 Bad Request` — `CANNOT_REMOVE_SELF`
Group creator tried to remove self (use Leave/Close instead).

#### `403 Forbidden` — `NOT_GROUP_CREATOR`
Authenticated user is not the creator of this group.

#### `404 Not Found` — `CONVERSATION_NOT_FOUND`
Conversation was not found, or is not a group conversation.

#### `409 Conflict` — `GROUP_CLOSED`
The group is closed.


## Mark As Read

Advances the authenticated user's read position in a conversation.

Idempotent: the server takes the greater of the stored and requested sequence, so retries and out-of-order acks are harmless.

Also doubles as a membership check — the row has to exist for the update to match anything, so a non-member or a nonexistent conversation both land on the same error code below.

### Request
```
PATCH /conversations/{conversationId}/read
```
#### Body
```
{
  "seq": number
}
```

### Response
#### `204 No Content`
The read position was advanced (or was already at or past the requested `seq` — both are treated as success). If the requested `seq` is actually newer than what was stored, a `MARKED_AS_READ` realtime event (`{ conversationId, seq }`) is sent to the user's own other sessions, so other open tabs/devices move their unread state too. No event is sent on a no-op (retry of an already-applied or stale ack).

#### `404 Not Found` — `MEMBERSHIP_NOT_FOUND`
User is not a member of the conversation, or the conversation doesn't exist. The response does not distinguish which.

> Note: sending a user message also calls this internally (`sendUserMessage` auto-acks the sender's own new message), which is why your own messages never show up as unread in your other sessions.


# Others

## Close Group Conversation

Closes a group conversation. This cannot be undone.

Authenticated user must be the creator of the group.

### Request
```
PATCH /conversations/{conversationId}/close
```

### Response
#### `204 No Content`
Group was successfully closed, or was already closed (idempotent).

On an actual close (not a no-op repeat): a `GROUP_CLOSED` event message is persisted (triggering a `NEW_MESSAGE` realtime event), and a dedicated `GROUP_CLOSED` realtime event is also broadcast to all members — see [realtime docs](./realtime.md#group_closed).

#### `403 Forbidden` — `NOT_GROUP_CREATOR`
Authenticated user is not the creator of this group.

#### `404 Not Found` — `CONVERSATION_NOT_FOUND`
Conversation was not found, or is not a group conversation.
